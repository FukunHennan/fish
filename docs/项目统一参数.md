# 项目统一参数

更新时间：2026-09-04

## 1. 服务端口

| 参数 | 值 | 说明 |
|---|---:|---|
| GUI | `8098` | 电脑端 React/Vite 页面 |
| Go Controller | `8081` | API、设备 WebSocket、权限和视觉代理 |
| Python Vision | `8091` | 仅监听 `127.0.0.1` |
| Python MJPEG | `8090` | 视觉服务内部视频回退端口 |
| 平板遥测 | `9998` | Python 视觉服务使用 |

公网只应通过 FRP 转发 Go Controller，不应转发 Python 端口或 ESP32 端口。

## 2. 设备通信

| 参数 | 值 | 说明 |
|---|---:|---|
| 协议 | WebSocket + UTF-8 JSON | ESP32 连接 Go 的 `/ws/device` |
| 协议版本 | `1` | 注册消息中的 `protocolVersion` |
| 设备身份 | MAC 地址 | 作为 `deviceId` |
| 控制器心跳 | 约 1 秒 | Go → ESP32 |
| ESP32 状态上报 | 约 1 秒 | ESP32 → Go |
| Go 设备离线判断 | 3 秒 | 超时后移除设备并通知 GUI |
| ESP32 控制器心跳超时 | 3000 ms | 超时后停止并断开 |
| 局域网发现周期 | 3 秒 | ESP32 广播 `device.announce` |

## 3. 运动参数

| 参数 | 默认/范围 | 说明 |
|---|---:|---|
| 默认频率 | `2.5 Hz` | 由 GUI/控制器使用 |
| 频率范围 | `0.3–5.0 Hz` | 控制器整理后下发 |
| 默认幅度 | `28°` | 由 GUI/控制器使用 |
| 幅度范围 | `0–90°` | 控制器整理后下发 |
| 偏置 | `-90°–+90°` | 根据设备标定范围处理 |
| 动作 | `forward` / `left` / `right` / `stop` / `idle` | 统一动作名称 |
| 设备模式 | `0–4` | `0=停止，1=待机，2=前进，3=左转，4=右转` |

控制器负责参数裁剪和每台设备的标定适配。设备收到有效命令后直接执行，并回报实际状态。

## 4. 视觉和视频

| 参数 | 值 | 说明 |
|---|---:|---|
| 采集尺寸 | `640×480` | Python/OpenCV |
| 目标帧率 | `30 FPS` | 实际值以摄像头状态为准 |
| YOLO 模型 | 可选 `.pt` 文件 | 从 GUI 选择，Python 加载 |
| 视频优先级 | WebRTC | 低延迟优先 |
| 视频回退 | MJPEG | WebRTC 不可用时使用 |
| MJPEG 质量 | `50` | 兼容回退 |
| 视觉控制间隔 | 约 `100 ms` | Python 计算并提交运动意图 |
| 视觉会话心跳 | `1 s` | 会话状态约定 |
| 视觉会话超时 | `3 s` | 超时后停止视觉运动 |

视觉识别目标和物理设备身份必须绑定。只识别、不绑定设备时，不允许自动控制机器鱼。

## 5. 权限

| 操作 | 普通用户 | 管理员 |
|---|---:|---:|
| 查看设备和状态 | 可以 | 可以 |
| 申请/释放控制权 | 可以 | 可以 |
| 手动运动控制 | 可以 | 可以 |
| 视觉识别和目标绑定 | 可以 | 可以 |
| RGB 和允许范围内的设备设置 | 可以 | 可以 |
| 普通账户管理 | 不可以 | 可以 |
| 固件上传和 OTA | 不可以 | 可以 |
| 管理员运维和紧急停止 | 受限 | 可以 |

## 6. 公网视频配置

如果公网 WebRTC 需要穿过不同网络，Python 可以配置 STUN/TURN：

```text
FISH_WEBRTC_STUN_URL=stun:...
FISH_WEBRTC_TURN_URL=turn:...
FISH_WEBRTC_TURN_USERNAME=...
FISH_WEBRTC_TURN_CREDENTIAL=...
```

FRP 只负责把浏览器请求送到 Go，不能替代 WebRTC 的 ICE、STUN 或 TURN 配置。
