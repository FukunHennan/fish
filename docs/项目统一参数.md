# 项目统一参数

## 视频

| 参数 | 值 | 说明 |
|---|---:|---|
| 采集宽度 | 640 | Python/OpenCV |
| 采集高度 | 480 | Python/OpenCV |
| 目标帧率 | 30 FPS | 摄像头、WebRTC、MJPEG |
| MJPEG 质量 | 50 | 仅作为兼容回退 |
| 视频策略 | WebRTC 优先 | 失败后回退 MJPEG |

## 寻迹

| 参数 | 值 | 说明 |
|---|---:|---|
| 控制位置 | 现场 Python | 浏览器不参与逐帧闭环 |
| 控制间隔 | 100 ms | Python 向 Go 发送最终运动参数 |
| 视觉会话心跳 | 1 s | 浏览器与现场服务的状态约定 |
| 视觉会话超时 | 3 s | 超时后停止寻迹 |

## 设备通信

| 参数 | 值 | 说明 |
|---|---:|---|
| 控制器心跳周期 | 1 s | Go → ESP32 |
| ESP32 心跳超时 | 3000 ms | 断联后停止 |
| 默认频率 | 2.5 Hz | 运动默认值 |
| 默认幅度 | 28° | 运动默认值 |
| 偏置范围 | -90° 到 +90° | 由 Go 根据标定处理 |

## 公网要求

公网浏览器只负责视频查看、路径绘制和高层操作。视频使用 WebRTC，寻迹计算和设备控制保持在现场电脑。公网部署时需要为 WebRTC 配置 STUN/TURN：

```text
FISH_WEBRTC_STUN_URL=stun:...
FISH_WEBRTC_TURN_URL=turn:...
FISH_WEBRTC_TURN_USERNAME=...
FISH_WEBRTC_TURN_CREDENTIAL=...
```
