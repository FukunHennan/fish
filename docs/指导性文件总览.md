## 五、摄像头与视觉的当前规则

- “服务器摄像头”由 Python 视觉服务枚举，负责共享视频、YOLO 识别、跟踪和循迹。
- 服务器摄像头列表包含被系统识别并通过可打开性检查的摄像头；电脑自带摄像头如果连接在运行视觉服务的电脑上，也会出现在服务器列表中。
- 视觉面板新增“电脑摄像头 · 本机预览”，使用当前浏览器的 `getUserMedia` 选择内置或 USB 摄像头，仅用于本机预览，不替代服务器识别和循迹。
- 通过 FRP 或其他内网穿透远程访问时，浏览器看到的“电脑摄像头”属于远程访问者所在电脑；它不会自动传给现场 Python 服务。
- 在线/离线只看设备真实心跳；视觉是否可用不改变机器鱼在线状态，也不阻断独立的手动控制。

## 七、整理建议

1. 对外或日常使用只保留“建议阅读顺序”中的五份文档。
2. 开发人员使用“当前有效文档”和“模块专项说明”。
3. 历史设计、计划和记录集中放在 `docs/archive/` 前，先检查链接和脚本引用，再做物理移动。
4. 不移动 `README.md`、`docs/README.md`、运行配置、协议文件和赛事规则原件。
5. 每次整理后执行前端构建、Go 测试，并检查文档中的端口与实际服务一致。
