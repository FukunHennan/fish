## 发现的问题

- 页面视觉识别开关显示可用，但通过浏览器自动化点击未触发状态变化；后续使用 Python 后端接口成功开启识别。需要继续确认是自动化热区问题、前端事件问题，还是权限回滚没有明显提示。
- 共享视觉入口和 workspace 入口容易混用。直连共享 `/sessions/...` 设置的 `targetDeviceId` 会被页面工作区状态覆盖，导致视觉运动启动不带设备身份，Go 侧返回 `CONTROL OFFLINE`。
- YOLO 模式下 `trackId` 在单鱼场景仍会跳变，例如从 `#51` 变为新的检测框，导致 `targetFound=false`，无法启动循迹。单鱼水池当前应使用 `single_fish` 模式。
- `single_fish` 模式下，workflow 曾出现 `positionReady=true`、`canStart=true`，但 `targetDetected=false` 的状态表达不一致；已修正为单鱼模式按可用控制位置表达目标就绪。
- 短路径接近终点时会很快进入 `HYBRID BRAKING`/`ARRIVED`，这符合当前 `arrival_radius_m=0.20`、`brake_radius_m=0.40` 的保守参数；后续需要用更长路径验证中段巡航，而不能只看短路径成功。

## 下一步

- 评估 YOLO tracker：单鱼模式可用，但 YOLO 锁定模式需要提高 trackId 稳定性或在短时丢 ID 时按空间邻近保持目标。
