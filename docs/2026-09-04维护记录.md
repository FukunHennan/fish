# 2026-09-04 控制可靠性维护记录

## 已完成的修复

- Go 联合限制中位、偏移和振幅，覆盖手动、键盘、视觉运动及向前标定；兼容旧标定。
- 视觉运动具有独立的 3 秒有效期；向前标定默认 3200 ms、最长 5000 ms。超时丢弃过期队列并提交停止，不由设备心跳续期。
- 视觉控制必须显式启动；超时、停止、手动接管或 OTA 后废止旧会话。Python 收到运动请求的 409 拒绝后停止继续排队。
- 租约清理在所有入口统一提交停止，控制权校验与命令入队使用同一租约锁。等待设备 ACK 放在锁外。
- 浏览器使用独立 clientId 和递增序号；接管清理旧运动并重置序号，旧浏览器不能继续发送运动。停止不受旧序号门槛阻挡，也不会污染新持有者的序号。
- 紧急停止先向所有设备入队，再逐一收集 ACK，避免第一台设备响应慢拖延其他设备的停止发送。
- 同步默认参数、认证开关、开发端口、systemd 部署方式和文档验证边界。
