# 多用户控制与视频使用说明

## 鱼的归属和控制

一名用户可以持有多条鱼，同一条鱼只能归属于一名用户。鱼离线、用户退出、运动超时以及服务重启均不自动释放归属；只有持有者主动释放或管理员强制释放才会解除归属。管理员全局急停仅停止运动。

归属属于账号，运动命令还必须属于当前浏览器的控制会话。重启服务、刷新页面或换浏览器后，鱼可能显示“我的归属 · 待恢复”。此时点击右侧“在本窗口恢复控制”，成功后才能发送运动命令。恢复会使该账号旧窗口的控制会话失效，不会自动恢复运动。

- 空闲鱼：选择鱼，点击“接管当前设备”。
- 我的归属、待恢复：点击“在本窗口恢复控制”。
- 我的控制：可以手动控制；点击“停止并释放控制权”解除归属。
- 他人控制：普通用户只读；管理员可以强制释放。

后端对运动、续期和普通停止命令校验账号及浏览器会话。不要通过删除归属文件解决界面问题；先恢复控制，或由管理员明确释放。

## 多鱼按键

逐条领取需要控制的鱼，在右栏“自定义按键”中设置前进、左转、右转和停止键。开启“多鱼键盘控制”后，切换所选鱼仍可使用该鱼的按键。不同键组可分别控制，例如 WASD 和 IJKL；相同键组会联动。

键盘只控制本窗口已领取的鱼。松开运动键会停止相应键盘运动；窗口失焦或切到后台停止本窗口键盘运动，但保留归属。按键和手动参数按账号保存在当前浏览器，尚不跨电脑同步。

## 摄像头与视频

服务器共享一台 Global Shutter Camera；项目屏蔽 USB2.0 FHD UVC WebCam，按设备名称判断，不固定屏蔽编号 0。

当前默认采集为 1920×1080、请求 30 FPS、MJPEG，YOLO 输入尺寸为 1920。采集缓冲从 1 帧调整为 2 帧后，独立实测由约 15.05 FPS 恢复到约 30.08 FPS；部署后的服务指标仍应单独复核。传感器型号与实物规格尚未完全核实，不再以 2592×1944 驱动输出推断原生像素。

“视频设置 → 本机清晰度”提供流畅、高清和超清。每个连接独立缩放，保持比例，不改变识别原图。当前为手动选择，不是自动网络自适应。本机预览关闭不关闭其他用户的视频。

视觉面板的“画面来源”可以选择“服务器摄像头”或“电脑摄像头”。服务器摄像头用于共享视频、YOLO 识别和循迹；电脑摄像头使用当前浏览器的本机权限，仅用于当前电脑预览。首次选择电脑摄像头时，浏览器会请求摄像头权限，并可在下方继续选择电脑内置摄像头或 USB 摄像头。通过内网穿透远程打开页面时，电脑摄像头指远程访问者当前使用的电脑，不会自动传回现场 Python 视觉服务；若需要让它参与识别，应将摄像头接到运行 Python 视觉服务的现场电脑，并在“服务器摄像头”列表中选择。浏览器通过公网域名访问本机摄像头时，通常还需要 HTTPS；`localhost` 和 `127.0.0.1` 属于浏览器允许的本地安全环境。

## 裁剪识别区域

管理员关闭识别和循迹后，在“视频设置 → 识别区域裁剪”框选矩形并应用。裁剪同步作用于显示和识别，可恢复全画面。设置保存于服务器；应用会重建视觉会话，需要重新选择目标并检查场地、方向标定，不释放鱼的用户归属。此功能不是透视矫正。

## 故障排查

- 显示我的控制，但命令被拒绝：确认使用新版页面。重启留下的归属应显示待恢复，点击恢复控制。
- 释放失败：新版普通释放传递布尔值 false；后端拒绝格式错误请求，不再继续处理部分解析的数据。
- 服务重启后无视频：新版本有效登录可跨重启保留，旧版本首次升级或会话过期需重新登录；新版页面会检查失效状态，避免继续显示旧摄像头数据。
- 视频短暂卡顿：后端不再因一次 1 秒缺帧直接终止轨道，前端为短暂网络断连保留 5 秒恢复窗口。运动安全超时独立保留。

## 尚未完成

服务器采集、裁剪和 YOLO 识别结果保持共享；每个“账号 + 浏览器 + 鱼”拥有独立的绑定、路径、方向和自动控制会话。只有当前浏览器持有该鱼控制权时才能进入对应视觉工作区，Python 运动命令还会由 Go 按相同账号、浏览器和设备复核。共享摄像头、识别开关、曝光及裁剪由管理员管理。目标丢失后的稳定身份恢复仍需继续改进，不能承诺识别编号永不变化。

登录有效期仍为原有 14 天，退出和账号会话撤销会持久化。服务重启不会自动恢复鱼的运动控制；仍需在当前窗口恢复控制。
