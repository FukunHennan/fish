# 桌面启动与部署

## 总览

项目提供 `scripts/fishctl` 作为统一的管理入口：启动、停止、重启、状态、日志、体检、打开控制台，以及生成桌面应用条目。它不依赖 GUI 工具包，可在无桌面环境运行；桌面图标只负责调用 `fishctl`。

`fishctl` 会自动识别当前部署模式：

- 检测到 systemd 用户单元 `fish-controller.service` → 使用 `systemctl --user` 管理，避免双重启动。
- 未使用 systemd → 调用现有 `scripts/start.sh` / `scripts/stop.sh`。

## 常用命令

```bash
python3 scripts/fishctl status              # 查看状态
python3 scripts/fishctl start               # 启动
python3 scripts/fishctl stop                # 停止
python3 scripts/fishctl restart             # 重启
python3 scripts/fishctl open                # 打开正式控制台 http://127.0.0.1:8081
python3 scripts/fishctl logs                # 查看运行日志
python3 scripts/fishctl logs --follow       # 持续跟踪日志
python3 scripts/fishctl doctor              # 检查依赖与运行环境
python3 scripts/fishctl install-desktop     # 安装桌面菜单条目
python3 scripts/fishctl uninstall-desktop   # 移除桌面条目
```

## 桌面启动

```bash
python3 scripts/fishctl install-desktop
```

安装后在应用菜单搜索：

```text
Fish Controller
```

双击会执行 `fishctl start-and-open`：若服务未运行则启动，健康检查就绪后自动打开浏览器控制台 `http://127.0.0.1:8081`。

桌面条目写入：

```text
~/.local/share/applications/fish-controller.desktop
```

如需迁移机器，只需重新执行 `install-desktop`，条目中的项目路径会按当前仓库位置生成，不写死旧路径。

## 部署依赖

- Go
- Node.js/npm（首次会安装前端依赖并构建）
- Python 及 `vision/.venv`（由 Go 自动托管）
- PlatformIO（仅编译/烧录固件需要）
- Linux 桌面环境需要 `python3`；`fishctl` 本身无需 Tkinter

缺失依赖时先运行：

```bash
python3 scripts/fishctl doctor
```

## 与 systemd 的关系

当前机器使用用户级 systemd：

```text
fish-controller.service    # Go Controller（同时托管 Python Vision）
fish-gui.service           # Vite 开发 GUI (8098)，可选
fish-cloudflared.service   # Cloudflare Tunnel，可选
```

当 `fish-controller.service` 存在时：

- `fishctl start/stop/restart` 会改用 `systemctl --user`；
- 不要再手动运行 `scripts/start.sh`，避免第二个进程与 systemd 冲突。

查看服务状态：

```bash
systemctl --user status fish-controller.service
systemctl --user status fish-gui.service
systemctl --user status fish-cloudflared.service
```

## 正式控制台与开发 GUI

- 正式控制台：`http://127.0.0.1:8081`（Go 内嵌构建产物，推荐日常与部署使用）。
- 开发 GUI：`http://127.0.0.1:8098`（Vite，前端热更新调试；由 `fish-gui.service` 或 `npm run dev` 提供）。

桌面条目与 `fishctl open` 打开的是正式控制台 8081，不依赖 Vite。

## 运行日志

启动脚本/`fishctl` 的输出写入：

```text
controller/.runtime/desktop-launcher.log   # fishctl 操作记录
controller/.runtime/fish-controller.log    # start.sh 启动的控制器输出
```

诊断记录仍在：

```text
controller/diagnostics/runs/
```

查看可用：

```bash
python3 scripts/fishctl logs
```

## 状态判断

`fishctl` 的健康判断：

- Go Controller：`http://127.0.0.1:8081/healthz`
- Python Vision：`http://127.0.0.1:8091/health`

设备是否真正在线，仍以 GUI 中 ESP32 的 heartbeat、注册状态和设备列表为准，不由健康接口代替。
