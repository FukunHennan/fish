# 机器鱼当前硬件清单

这是固件 `2.0.0` 使用的实际硬件定义：

- 控制板：ESP32-C3 Super Mini，按原 XIAO PCB 焊盘对齐
- 舵机：1 个，芯片 `GPIO2`，对应原 XIAO `D8` 焊盘
- 电池电压采样：芯片 `GPIO4` ADC1，对应原 PCB `A0` 焊盘
- 分压：`20K` 上臂 + `10K` 下臂，固件按 `3.0:1` 还原电池电压
- 电池范围：空电 `7.0V`，满电 `7.4V`
- 板载状态灯：1 个单色 LED，芯片 `GPIO8`，高电平点亮；只用于显示设备运行状态
- RGB、光感和 I2C 传感器：无，固件不会声明或控制这些能力

注意：7.4V 经 20K/10K 后约为 2.47V。仍建议用万用表确认 GPIO4 的实际电压，再进行长时间运行。
