# Fish Control GUI

这是电脑端 GUI 的运行入口。页面使用正式 React 控制台，并通过 Vite 代理连接本机
`8081` 控制器，因此这里的操作会访问真实设备和真实通信层，不再使用 mock 状态。

## 设计重点

- 左侧设备栏固定注册顺序，状态变化不会导致重排。
- 中间区域只承载视频/视觉主工作区。
- 右侧只显示当前设备的状态和控制项。
- 手动、视觉、设置使用同一套桌面控制台骨架。
- 页面包含真实设备切换、运动控制、键盘 `W/A/S/D`、视觉模式、账户权限和设置操作。
- 普通用户和管理员看到不同的设置菜单；固件上传与 OTA 仍只对管理员开放。
- 手动控制权明确分为“空闲 / 我的控制 / 他人控制”，并显示真实租约状态。
- 视觉识别目标与物理设备分离，可以切换错误识别目标后再重新绑定。

## 预览

运行：

```bash
npx --yes vite --host 127.0.0.1 --port 8098
```

打开 `http://127.0.0.1:8098/`。控制器服务需要同时运行在
`http://127.0.0.1:8081/`。
