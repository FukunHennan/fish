# GUI Prototypes

这里存放可直接用浏览器打开的单文件 HTML 交互设计稿。

## 两条 GUI 设计线

- `control-center.html`：当前版本设计稿，尽量反映已经实现或正在使用的主控制台界面。
- `control-center-planned.html`：规划版本设计稿，用于讨论下一阶段界面与功能，不代表所有功能已经实现。

## 其他专项设计稿

- `ap-wifi-provisioning.html`：AP 配网
- `battery-status.html`：电池状态展示
- `ota-settings.html`：OTA / 设置（如后续需要独立设计）
- `vision-workspace.html`：视觉工作区（如后续需要独立设计）

原型用于 UI/UX 评审。确认规划版设计后，再逐项同步到 `controller/frontend/`，并在功能真实落地后更新当前版本设计稿。
